Haushaltsbudget
Einrichten
Erstelle einen neuen Haushalt oder tritt einem bestehenden bei. Daten werden über das Internet zwischen beiden iPhones synchronisiert.
Neuen Haushalt erstellen
Generiert einen 6-stelligen Code. Teile ihn (oder den Link) mit dem zweiten iPhone.
— ODER —
Bestehendem Haushalt beitreten
Gib den 6-stelligen Code ein, den das erste iPhone angezeigt hat — oder öffne den geteilten Link direkt.
Sync-Technologie: Die App nutzt JSONBin.io als kostenlosen Cloud-Speicher. Kein Account nötig. Beide iPhones lesen und schreiben dieselben Daten — alle 15 Sekunden automatisch aktualisiert. Daten sind mit deinem persönlichen Code geschützt.
